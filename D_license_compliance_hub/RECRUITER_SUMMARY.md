# Recruiter summary - Project D

**Multi-state license compliance hub** · SQLite · Python · Excel (formulas, conditional formatting) · Plotly · synthetic data

**What it is:** A compliance view for a fictional eight-site infusion network. It tracks staff license renewals, document
presence, site licenses, and medical-director coverage over time, with a per-site pass/fail matrix.

**Highlights:**

- Status is computed from dates. It caught two expired licenses still typed "Active".
- Document flags are audited against the document index (two false "on file" flags).
- Effective-dated director coverage found an uncovered site and an overlap of two primaries.
- The Excel tracker re-ages every license from one as-of cell.

**Honest scope:** On the job I organized a nursing license register and helped structure a document-library hub. The reminder
schedule here is a plan, not a deployed automation, and all data is fabricated.
